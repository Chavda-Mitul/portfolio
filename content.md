## 02 / Selected Works

### 1. SentinelInvoice (AI / Automation)
**Repo:** https://github.com/Chavda-Mitul/invoice-anomaly-detection
**Description:** Autonomous AI invoice auditing engine that parses PDF invoices via LlamaParse OCR, extracts structured fields with Gemini, validates line-item math, and flags anomalies via a Tavily-powered ReAct agent with LangGraph human-in-the-loop checkpoints.
**Tech Stack:** LangGraph, LangChain, Google Gemini, Groq, LlamaParse, Tavily, PostgreSQL, Express.js, React

### 2. Code-RAG (RAG / Knowledge Graph)
**Repo:** https://github.com/Chavda-Mitul/Codebase-RAG
**Description:** Production-grade codebase Q&A system that ingests any GitHub repo, parses it with tree-sitter AST, and stores a Neo4j knowledge graph. Answers via hybrid RRF retrieval (vector + BM25 + graph traversal) with a CRAG corrective loop.
**Tech Stack:** LangGraph, LangChain, Neo4j, Groq LLaMA-3.3, FastAPI, Next.js, tree-sitter, Python

### 3. FlashCommerce (Backend / Systems)
**Repo:** https://github.com/Chavda-Mitul/flash-sale
**Description:** High-traffic flash sale backend built to handle thousands of concurrent buyers without overselling. Uses Redis Lua atomic scripts for microsecond inventory reservation and two-layer storage.
**Tech Stack:** Node.js, Fastify, TypeScript, Redis, PostgreSQL, Stripe, JWT, Docker, Jest

### 4. Satellite Surveillance (Real-time / Visualization)
**Repo:** https://github.com/Chavda-Mitul/surveillance
**Description:** Real-time 3D satellite tracking app that visualises thousands of active satellites over a Cesium.js globe with live TLE orbital data streaming and orbital path predictions.
**Tech Stack:** React 18, TypeScript, Cesium.js, Node.js, Fastify, Redis, satellite.js

### 5. Shared-Sketch (Real-time / Collaboration)
**Repo:** https://github.com/Chavda-Mitul/Shared-Sketch
**Description:** Real-time collaborative drawing platform that lets multiple users sketch simultaneously on a shared canvas with WebSocket-based synchronization.
**Tech Stack:** TypeScript, WebSockets, Canvas API
